# Dドライブリフレッシャー

Dドライブのメモリ内のデータの電荷漏れによる劣化を防ぐためのスクリプトです。

家庭用のSSDで頑張ってデータをアーカイブするために作られています。

現在は、Dドライブ以外でも使えるように拡張されています。

2026-09-23時点で、機能はすべて特定のディレクトリに対して特定の操作を再帰的に実行するものであり、以下のバリエーションがあります。

1. ディレクトリ全体のハッシュをそのディレクトリ直下の`.hash.toml`にとる
2. 1で取ったハッシュを正本に、全体を再ハッシュして照合し、ずれがあれば指摘する。
3. ディレクトリの子孫ファイルすべてをロードする。ロードするだけで明示的な書き込みはしない。ロードエラーによって物理破損を検知したり、SSDの実装依存でリフレッシュを促す。
4. ディレクトリの中に`A/`,`B/`という二つのディレクトリがあり、片方にすべての中身が入っていることを前提に、A-B間でデータをコピーしあう。コピーできたファイルは、コピー元から削除される。A-Bで全データが交互に移動するイメージ。mvではなくcpなので、強制的に全データをリフレッシュできる。
